# Autonomous Git Workflow Directive

## Permanent Instruction
- **Always Commit and Push By Yourself:**
  - After making code changes and verifying them (`npm test`, `npm run build`), immediately stage, commit with a concise conventional commit message, and push to `origin/main`.
  - Do NOT ask for permission or wait for user confirmation to commit and push changes.
  - Keep the remote repository in sync after every implemented modification.
